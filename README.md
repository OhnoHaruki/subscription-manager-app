# Subscription Manager App

サブスクリプションや固定費をまとめて管理するためのスマホアプリです。

毎月・毎年発生する支払いを見える化し、支払い忘れやクレジットカードの有効期限切れによる決済失敗を防ぐことを目的としています。

## アプリ概要

このアプリでは、動画配信サービス、音楽サービス、クラウドストレージ、保険、通信費など、定期的に発生する支払いを登録して管理できます。

サブスクごとの金額、支払い周期、支払い方法、分類タグを管理することで、月ごと・年ごとの固定費を把握しやすくします。

## 目的

- サブスクの支払い管理を楽にする
- クレジットカードの有効期限切れによる支払い失敗を防ぐ
- 解約や支払い方法変更をスムーズにする
- 毎月・毎年の固定費を把握し、家計管理に役立てる

## 主な機能（MVP）

### サブスク管理

- サブスクの登録
- サブスク情報の編集
- サブスクの削除
- サブスク一覧表示

### 支払い方法管理

- クレジットカードの登録
- 銀行口座の登録
- サブスクごとの支払い方法設定

### 分類・集計

- タグによるサブスク分類
- 月額合計の表示
- 年額合計の表示

## 将来的な機能

- Gmail連携によるサブスク検出
- クレジットカードの有効期限アラート
- 解約導線のワンタップ化
- Web対応
- 支払い履歴の管理
- サブスクの利用頻度メモ

MVPでは、次のような画面を想定しています。

- サブスク一覧画面

## 開発方針

まずはMVPとして、サブスクを手動で登録し、一覧表示と金額集計ができる状態を目指します。

その後、通知機能やGmail連携などを追加し、支払い失敗の予防や解約手続きの効率化につなげていきます。

## 👨‍💻 Developer Zone

開発環境のセットアップや実機テストの手順を記載します。

### 1. プロジェクトの初期セットアップ

1. **リポジトリのクローン**:
   ```bash
   git clone <repository-url>
   cd subscription-manager-app
   ```
2. **Flutter環境の確認**:
   プロジェクトルートにある `.tool-versions` ファイルの Flutter バージョンを使用してください。
   ```bash
   asdf install
   ```
3. **依存パッケージのインストール**:
   ```bash
   flutter pub get
   ```
4. **環境変数の設定**:
   `.env.example` を参考に `.env` ファイルを作成し、Supabase の URL と Anon Key を設定してください。
   ```bash
   cp .env.example .env  # 存在する場合
   # .env を編集して SUPABASE_URL と SUPABASE_ANON_KEY を設定
   ```

### 2. iPhone での動作確認

実機（iPhone）でデバッグを行う手順です。

1. **プロジェクトを開く**:
   ```bash
   open ios/Runner.xcworkspace
   ```
2. **署名の設定**:
   Xcode で `Runner` プロジェクトを選択し、`Signing & Capabilities` タブで自身の Apple ID を追加し、適切な Team を選択してください。
3. **デバイスの接続と実行**:
   iPhone を Mac に接続し、Xcode のデバイスセレクタから接続した iPhone を選択。
4. **ビルドと実行**:
   Xcode の実行ボタンを押すか、ターミナルで以下を実行します。
   ```bash
   flutter run
   ```

### 3. CI/CD とテスト

- **テストの実行**:
  ```bash
  flutter test
  ```
- **コード解析**:
  ```bash
  flutter analyze
  ```
